Startup working directory
=========================

MUSHclient changes its working directory to the executable folder before loading
preferences, worlds, plugins, or Lua. A shortcut's "Start in" setting or another
launch directory no longer redirects startup file lookup.

MUSHclient.ini and mushclient_prefs.sqlite are consequently read beside the
executable. Move those preferences there if they were previously kept in a
separate launch directory.

Directory APIs and explicit ChangeDir behavior are unchanged.

To check startup lookup from a conflicting launch folder and a relocated
installation, run from an x86 Visual Studio Developer shell with MFC installed:

    powershell -NoProfile -File tests/check_executable_paths.ps1
